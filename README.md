<h1><strong>Servix</strong></h1>

The idea behind the app is to connect users with local service providers such as plumbers, electricians, cleaners, mechanics, painters, and other everyday services.

Service providers will be displayed in the app, and users can search for the provider that best suits their needs in terms of location, price, service specifications, etc.

<h2><strong>Current Version</strong></h2>

Right now, the app contains:

- A simple home screen
- Service categories
- Provider cards
- Favorite button interaction

<h2><strong>Possible Features To Add Later</strong></h2>

Some ideas planned for future versions of the project:

- User authentication / account creation
- Service booking system
- Search functionality
- Provider profiles
- Service filtering
- Ratings and reviews
